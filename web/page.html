Nexus searches with alpha-beta, quiescence, a transposition table, null-move pruning and late move reductions, and evaluates positions with a 768→128×2→1 network trained on 191.5 million positions from the Lichess evaluation database (CC0). Strength here is set by node count, because WebAssembly has no clock for the engine to time itself by.
